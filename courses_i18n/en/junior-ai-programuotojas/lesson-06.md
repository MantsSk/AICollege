# Portfolio Project and Presentation

For a junior programmer, "I completed a course" is not enough. You need a small, understandable project you can explain.

**After this lesson you will be able to:**

- tell a good portfolio project from "yet another tutorial";
- write a README that answers an interviewer's questions;
- prepare to explain the project in 5 minutes.

## A good AI portfolio project

It should have:

- a clear problem;
- simple setup;
- README;
- example input and output;
- limits and safety notes;
- a few tests;
- screenshot or demo GIF if there is a UI.

## Project Ideas

- Email generator with tone selection.
- Document summary tool.
- Python learning chatbot.
- Resume review assistant.
- Task planning agent.
- Mini RAG tool for personal notes.

## README Template

```markdown
# Project Name

## Problem
What problem does it solve?

## Features
- ...

## How to Run
Example: `python app.py`

## How AI Is Used
Briefly explain the model, prompts, and boundaries.

## Safety
What data should not be uploaded? What does the app not do?

## What I Learned
3-5 bullet points.
```

## Check yourself

**1. What does the "Safety" section of the README require, and why does it impress?**

<details class="selfcheck" markdown="1">
<summary>Show answer</summary>

Describing what data must not be uploaded and what the app deliberately does not do. It shows you understand AI's limits and risks — a rare skill among beginners.

</details>

**2. Why is a small finished project better than a big unfinished one?**

<details class="selfcheck" markdown="1">
<summary>Show answer</summary>

In an interview you must explain the project in minutes. A finished small project with a README, tests, and clear boundaries shows the full work cycle — an unfinished big one only shows ambition.

</details>

**3. What must the README contain if the project uses AI?**

<details class="selfcheck" markdown="1">
<summary>Show answer</summary>

Which model is used, what the prompts are, what the boundaries are — and what the app deliberately does not do. The AI part must be explainable, not magic.

</details>

## Final Project

Choose one project and finish it. The goal is not to build a huge system. The goal is to have a project you can show and explain in 5 minutes.

> **Task check:** paste your README to the mentor and ask: "Read this as an interviewer: what questions would you ask, and which does the README fail to answer?"

> **Mentor tip:** Ask "Help me choose an AI portfolio project based on my current Python level."

Congratulations. You now have a clear path from learning to portfolio.
