# Documents, PDFs, and Summaries

AI is useful when you need to understand long text quickly: rules, contracts, articles, learning material, or meeting notes.

**After this lesson you will be able to:**

- prepare a document safely before uploading it to an AI tool;
- get a summary that separates facts from uncertainties;
- use document Q&A mode with supporting evidence.

## Safe Document Work

Before uploading a document, check:

- whether it contains personal data;
- whether you are allowed to upload it to the chosen AI tool;
- whether the document is confidential;
- whether the answer must be checked in an official source.

If the text is sensitive, replace names, companies, amounts, and exact dates with generic labels.

## Summary Prompt

```text
Summarize this text.

Provide:
1. the 5 most important ideas;
2. action items, if any;
3. unclear parts;
4. what I should verify myself.

Do not draw conclusions that are not in the text.
```

## Document Q&A Mode

Instead of one summary, you can use AI as a document assistant:

```text
Answer only using the provided document text.
If the answer is not there, write "I did not find this in the text."
For each answer, mention which part of the text supports it.
```

## Check yourself

**1. What should you check before uploading a document to an AI tool?**

<details class="selfcheck" markdown="1">
<summary>Show answer</summary>

Whether it contains personal data, whether it is confidential, whether your organization allows uploading it, and whether the answer must be verified in an official source.

</details>

**2. Why does the summary prompt say "do not draw conclusions that are not in the text"?**

<details class="selfcheck" markdown="1">
<summary>Show answer</summary>

Models tend to "round up" — adding logical-sounding conclusions that are not actually in the text. That boundary keeps the summary anchored to the document.

</details>

**3. What makes document Q&A mode better than a single summary?**

<details class="selfcheck" markdown="1">
<summary>Show answer</summary>

You can ask exactly what matters to you, and requiring the supporting passage lets you quickly verify the answer really comes from the document.

</details>

## Mini Project

Choose one text: rules, an article, a contract excerpt, or learning material. Prepare:

- a short summary;
- an action list;
- 5 follow-up questions;
- a list of facts that must be verified.

> **Task check:** paste the summary you got to the mentor and ask: "Which points of this summary come directly from the text, and which are interpretation?"

> **Mentor tip:** Ask "Help me extract only what matters for making a decision from this document."
