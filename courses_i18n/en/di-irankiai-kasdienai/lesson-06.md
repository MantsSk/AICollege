# Final Project - Your AI Toolkit

By the end of this course, you should have not only knowledge, but a real set of prompts you use day to day.

## What will you create?

Create a set of 10 prompts:

1. polite email;
2. text shortening;
3. resume or LinkedIn review;
4. document summary;
5. learning coach;
6. decision table;
7. weekly plan;
8. idea generation;
9. privacy check;
10. answer verification.

## Prompt Quality Rules

Each prompt should include:

- clear goal;
- context;
- format;
- boundaries;
- verification step.

## Final Template

```text
Task: [what AI should do]
Context: [my situation]
Format: [how to present it]
Boundaries: [what to avoid]
Verification: [what to mark at the end]
```

## Final Work

Create one document called "My AI Toolkit." Keep your best prompts there and improve them after each use.

> **Mentor tip:** Ask "Help me create a 10-prompt toolkit based on my everyday tasks."

Congratulations. You now have a practical system for using AI every day.
