# Portfolio projektas ir pristatymas

Junior programuotojui neužtenka „pasidariau kursą“. Reikia parodyti mažą, suprantamą projektą, kurį gali paaiškinti.

**Po šios pamokos galėsi:**

- atskirti gerą portfolio projektą nuo „dar vieno tutorial”;
- parašyti README, kuris atsako į interviuotojo klausimus;
- pasiruošti projektą paaiškinti per 5 minutes.

## Geras AI portfolio projektas

Jis turi:

- aiškią problemą;
- paprastą paleidimą;
- README;
- pavyzdinius įvesties ir išvesties duomenis;
- ribų ir saugumo aprašymą;
- kelis testus;
- ekrano nuotrauką arba demo GIF, jei yra UI.

## Projekto idėjos

- Lietuviškų laiškų generatorius su tono pasirinkimu.
- Dokumento santraukų įrankis.
- Python mokymosi chatbotas.
- CV peržiūros asistentas.
- Užduočių planavimo agentas.
- Mini RAG įrankis asmeniniams užrašams.

## README šablonas

```markdown
# Projekto pavadinimas

## Problema
Kokią problemą sprendžia?

## Funkcijos
- ...

## Kaip paleisti
Pavyzdys: `python app.py`

## Kaip naudojamas DI
Trumpai paaiškink modelį, promptus ir ribas.

## Saugumas
Kokių duomenų nekelti? Ko programa nedaro?

## Ką išmokau
3-5 punktai.
```

## Pasitikrink save

**1. Ko README šablone reikalauja skyrius „Saugumas“ ir kodėl jis daro įspūdį?**

<details class="selfcheck" markdown="1">
<summary>Rodyti atsakymą</summary>

Aprašyti, kokių duomenų nekelti ir ko programa nedaro. Jis rodo, kad supranti DI ribas ir rizikas — retas įgūdis tarp pradedančiųjų.

</details>

**2. Kodėl mažas užbaigtas projektas geriau už didelį nebaigtą?**

<details class="selfcheck" markdown="1">
<summary>Rodyti atsakymą</summary>

Interviu metu projektą reikia paaiškinti per kelias minutes. Užbaigtas mažas projektas su README, testais ir aiškiomis ribomis parodo visą darbo ciklą — nebaigtas didelis rodo tik ambiciją.

</details>

**3. Kas privalo būti README, jei projektas naudoja DI?**

<details class="selfcheck" markdown="1">
<summary>Rodyti atsakymą</summary>

Koks modelis naudojamas, kokie promptai, kokios ribos — ir ko programa specialiai nedaro. DI dalis turi būti paaiškinama, ne magija.

</details>

## Baigiamasis projektas

Pasirink vieną projektą ir padaryk jį iki galo. Tikslas nėra sukurti didelę sistemą. Tikslas — turėti projektą, kurį gali parodyti ir paaiškinti per 5 minutes.

> **Užduoties patikra:** įklijuok savo README mentoriui ir paprašyk: „Perskaityk kaip interviuotojas: kokių klausimų kiltų ir į kuriuos README neatsako?“

> **Mentoriaus patarimas:** paklausk „Padėk man pasirinkti AI portfolio projektą pagal mano dabartinį Python lygį.“

Sveikinu — dabar turi aiškų kelią nuo mokymosi iki portfolio.
